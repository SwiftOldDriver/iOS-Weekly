### 🐕 [Apple Reference Image](https://mjtsai.com/blog/2026/09/16/apple-reference-image/)

[@阿权](https://github.com/bqlin)：[Apple Reference Image](https://security.apple.com/blog/apple-reference-image/) 是 iPhone18 Pro 的特供功能，用于密码学验证照片是真实相机传感器拍摄，对抗 AI 伪造图片，同时保护用户隐私，不暴露拍摄者身份。

基本原理：

1. 设备定期预取加密时间戳做时间下限，拍完照片再拿第二个时间戳做时间上限，把两个时间戳与传感器原始数据一起签名保存，生成安全数字底片；
2. 用户操作生成参考图像，底片上传苹果 PCC 私有云，在可审计安全环境完成图像处理；
3. 处理完成由苹果签名服务签名输出参考图像；支持单张照片、整台传感器全部凭证的吊销撤销。

这项技术不会用公开凭证把多张照片追溯绑定到同一个拍摄设备（避免用于用户追踪），兼顾可验证真实性与用户隐私。

### 🐢 [Inside iOS 27's Reworked Stub Islands](https://codecolor.ist/posts/2026-06-15-ios27-reworked-stub-islands/)

[@Smallfly](https://github.com/iostalks)：文章从反汇编角度分析 iOS 27 在 `dyld_shared_cache` 中对 stub islands 的调整：移除冗余 `__auth_stubs`、合并 Objective-C 元数据，并引入新的跳板编码方式来减少内存加载和指针认证开销。适合关注 dyld、Objective-C runtime、二进制优化和 Apple 平台性能细节的读者。

### 🐎 [The new JSON project format in Xcode 27.2](https://sarunw.com/posts/xcode-json-project-format-xcproj/)

[@david-clang](https://github.com/david-clang)：Xcode 27.2 开始，项目配置可以从传统的 `project.pbxproj` 切换为 JSON 格式的 `project.xcproj`，这不是一次构建能力升级，而是一次面向 Git 协作、代码审查和项目可维护性的基础设施改造。传统 `.pbxproj` 是由大量随机 ID 组成的扁平对象图，新增一个 Swift 文件，通常会同时改动文件引用、编译条目、分组和 Build Phase 等多个区域；两位开发者在不同分支各加一个文件，也可能造成无意义的合并冲突。`.xcproj` 用层级化 JSON 表达相同信息：

- 文件直接嵌套在所属 group 中；
- 通过 target-membership 标记编译归属；
- 仅 target、产品等必要对象保留 ID；
- 公共 Build Settings 只保存一次，Debug / Release 的差异用条件键表达。

`.xcproj` 的优点是：配置更短、diff 更可读、冲突范围更小，也更容易审查和自动化处理。

### 🐎 [Beta Previews: LazyState](https://www.pointfree.co/blog/posts/223-beta-preview-lazystate)

[@阿权](https://github.com/bqlin)：Xcode27 将`@State`升级为宏，行内默认值支持惰性初始化，但不支持在 init 中利用外部入参惰性初始化状态；在 init 直接赋值会反复创建对象。苹果建议用`onAppear + Optional`，但会引入可选污染、手写 Binding、多余容器等一堆问题。

**LazyState 库**：Point‑Free 封装 SwiftUI 内部已存在的未公开`LazyState`类型，提供`@LazyState`宏。在 init 传入闭包，利用外部参数惰性创建状态对象，视图生命周期仅初始化一次，正常支持`$`生成 Binding，消除可选与 onAppear 样板代码。

**限制**：父视图更新参数重建子视图，**不会刷新子视图 LazyState 内部状态**，与 onAppear 方案行为相同；当前仅限 Point‑Free Max 会员 Beta 试用。

### 🐎 [MotionPhotoKit](https://github.com/ronny917/MotionPhotoKit)

[@极速男孩](https://github.com/ztlyyznf001)：MotionPhotoKit 是一个开源跨端动态照片库，支持 Android、iOS 和鸿蒙。它将不同平台的动态照片转换为统一格式，支持原生播放和保存到系统相册，并可复用应用已有的下载、鉴权与缓存能力，适合聊天、社区和信息流等场景。
